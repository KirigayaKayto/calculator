# Калькулятор

Калькулятор для Android и ПК без рекламы. Главное — примеры записываются **как в учебнике**: дроби столбиком, корни с чертой, степени сверху (как на Casio ClassWiz), а ответ показывается обыкновенной дробью (3½) с переключением на десятичную. Ещё есть история, блокнот-калькулятор, конвертер единиц и валют. Это PWA: ставится из браузера, работает без интернета.

Ввод с клавиатуры ПК: `/` — дробь, `^` — степень, `sqrt` — корень, `tg`, `lg`, `pi`; стрелки ходят по дробям и корням, Enter — ответ, Esc — очистить.

## Команды

```
npm install       # один раз; кэш npm лежит на D: (см. .npmrc)
npm run dev       # разработка: http://localhost:5173
npm test          # тесты вычислительного ядра
npm run check     # проверка типов
npm run build     # сборка в dist/
npm run preview   # посмотреть сборку: http://localhost:4173
```

## Устройство

- `src/engine/` — вычисления без интерфейса (mathjs, 64 значащие цифры):
  - `latex.ts` — перевод учебной записи из поля MathLive (LaTeX) в выражение: дроби, смешанные числа, корни, tg/ctg/lg;
  - `exact.ts` — точный ответ обыкновенной дробью (5/6, −3½);
  - `math.ts` — настройка mathjs: кириллица в именах, русские единицы, градусы и радианы, `log` = lg;
  - `input.ts` — разбор того, что ввёл человек: × ÷ −, «в» вместо `to`, десятичная запятая, пробелы в числах;
  - `format.ts` — вывод: «1 000 000», «1,8×10¹⁹», деньги до копеек;
  - `notebook.ts` — блокнот: переменные, «итого», подписи, комментарии;
  - `currency.ts` — курсы валют (open.er-api.com, запасной вариант — cbr-xml-daily.ru).
- `src/ui/` — экраны на Svelte 5.
- `src/lib/state.svelte.ts` — общее состояние; всё сохраняется в localStorage этого устройства.

## Установка

- **ПК:** откройте адрес приложения в Edge или Chrome и нажмите «Установить» в адресной строке (или «Установить на это устройство» в настройках приложения).
- **Android:** откройте адрес в Chrome, затем «⋮» → «Установить приложение». Для установки на телефон приложение должно открываться по HTTPS, например с GitHub Pages.
